# 로드맵

로그라이크 한 판 → 계정 단위로 성장하는 와우풍 액션 RPG로 확장한다. 모든 작업은 `server` 브랜치에서 진행하고 `main`(GitHub Pages)은 그대로 둔다.

## 확정된 결정 (2026-10-02)

| 항목 | 결정 |
|---|---|
| 게스트 | 기본 플레이만 가능. 장비 · 가챠 · 랭킹 · 특성은 로그인 필수 |
| 가챠 재화 | 가챠마다 다른 재화 (아래 "재화" 참고). 골드는 특성 구매용 |
| 기존 달라란 도서관(영구 강화) | 새 특성 시스템으로 대체. 사용 유저가 없으므로 환급 로직 불필요 |
| 스테이지 테마 | 오리지널(클래식) 컨셉으로 시작 → 확장팩 단위로 챕터 추가 |
| 독자 특성 | 직업 특성과 별도로 로그라이크 진행에 직접 영향을 주는 계정 공용 특성 페이지 |

## 핵심 원칙

### 서버가 경제를 관리한다
- 세이브 통째 업로드(`PUT /api/save`) 폐지. 재화 · 아이템 · 특성은 서버 API로만 변경
- 가챠 결과는 서버에서 굴린다
- 판 시작 시 서버가 런 ID 발급 → 종료 시 결과 보고 → 서버가 실제 경과 시간 · 처치 수 상한 등으로 검증 후 보상 계산
- 전투는 브라우저에서 돌아 완벽한 조작 방지는 불가. 랭킹 상위 기록은 런 로그를 남겨 사후 검증
- 장기적으로 파티 · 레이드는 서버 권위 실시간(WebSocket) 구조가 필요 → 전투 로직과 렌더링 분리를 유지

### 밸런스
1. 판 밖 성장(특성 + 장비 + 보석 + 마법부여) 상한: 최고 수준에서 기본 대비 화력 약 2.5~3배
2. 스테이지 난이도는 권장 아이템 레벨에 맞춰 상승
3. 판 안의 레벨업 선택이 주된 재미로 남도록 판 밖 성장은 "기초 체력" 역할
4. 2차 능력치는 와우처럼 수치 → % 변환, 일정 % 이상 효율 감소
5. 모든 수치 변경은 봇 시뮬레이터(스테이지 × 장비 수준별 클리어율 · 시간 표)로 검증
6. 랭킹에 아이템 레벨을 함께 표시

## 재화

| 재화 | 주 획득처 | 사용처 |
|---|---|---|
| 골드 | 모든 판 | 직업 특성 · 달라란 도서관 포인트 구매, 특성 초기화 |
| 정의의 휘장 | 스테이지 보스 처치 · 클리어 | 장비 뽑기 |
| 신비한 가루 (상위: 영원의 정수) | 장비 분해 | 마법부여 뽑기 |
| 미가공 원석 | 엔드리스 진행 · 일일 퀘스트 | 보석 뽑기 |

획득처를 나눠 다양한 플레이(클리어 / 파밍 / 엔드리스 / 퀘스트)에 각각 동기를 준다.

## 특성: 두 페이지

### 직업 특성 (캐릭터별)
와우 특성 트리 방식. 일정 포인트를 써야 다음 줄이 열리고, 줄마다 택일 선택지가 있다. 포인트는 골드로 구매(가격 점증), 골드를 내고 초기화.

### 달라란 도서관 (계정 공용, 이 게임만의 로그라이크 특성)
레벨업 · 상자 선택지 자체를 바꾸는 특성. 예시:

| 특성 | 효과 |
|---|---|
| 운명의 주사위 | 다시 굴리기 +1 (최대 3) |
| 넓어진 시야 | 레벨업 선택지 3 → 4개 (트리 깊은 곳, 고가) |
| 학파 연구 | 택일: 자동 시전 / 핵심 주문 / 능력치 계열 출현 확률 증가 |
| 행운의 동전 | 높은 등급(희귀 · 영웅) 출현 확률 증가 |
| 추방 | 판마다 선택지 N개를 그 판에서 영구 제외 |
| 봉인 | 선택지 하나를 다음 레벨업까지 유지 |
| 준비된 주문서 | 시작 시 무작위 자동 시전 주문 1개 습득 |
| 보물 사냥꾼 | 정예 상자 출현 증가, 상자 선택지 +1 |
| 전설의 부름 | 전설 효과 출현 확률 증가 |
| 영혼석 | 판마다 1회 부활 |

## 스테이지

### 챕터 1: 오리지널
| # | 스테이지 | 최종 보스 |
|---|---|---|
| 1 | 죽음의 폐광 | 에드윈 밴클리프 |
| 2 | 그림자송곳니 성채 | 대마법사 아루갈 |
| 3 | 붉은십자군 수도원 | 종교재판관 화이트메인 |
| 4 | 스칼로맨스 | 암흑스승 간들링 |
| 5 | 스트라솔름 | 남작 리븐데어 |
| 공격대 | 화산 심장부 → 검은날개 둥지 → 낙스라마스 | 라그나로스 / 네파리안 / 켈투자드 |

- 스테이지마다 적 구성 · 보스 기술 · 시간(8~10분) · 권장 아이템 레벨이 다르다
- 일반 / 영웅 난이도. 영웅은 일반 클리어 후 개방
- 클리어 시 "보상 받고 종료" 또는 "엔드리스 계속"(쐐기돌식 단계 상승 + 접두어)
- 현재 콘텐츠(얼음왕관의 시련, 리치 왕)는 "특별 스테이지"로 유지했다가 리치 왕의 분노 챕터 피날레로 편입

## 단계

### Phase 0. 기반 공사
- [ ] 직업 구조 분리 (자원 · 스킬 목록 · 레벨업 풀 · 액션바 · HUD · 봇 가중치를 직업 데이터로)
- [ ] 서버 경제 스키마 (캐릭터 · 재화 · 특성 · 런 · 랭킹), 세이브 업로드 폐지
- [ ] 런 시작 / 종료 API와 결과 검증, 서버 보상 계산
- [ ] 밸런스 시뮬레이터 (봇을 화면 없이 여러 판 돌려 표로 출력)

### Phase 1. 로비 · 스테이지 · 랭킹
- [ ] 달라란 허브형 로비 (캐릭터 · 스테이지 · 특성 · 장비 · 뽑기 · 랭킹 · 게시판, 금고 · 퀘스트 자리)
- [ ] 스테이지 데이터 구조 + 오리지널 1~2단계 (적 · 보스 · 시간)
- [ ] 클리어 후 종료 / 엔드리스 선택, 엔드리스 단계 · 접두어
- [ ] 랭킹 (스테이지 × 난이도 × 직업, 주간 / 전체)
- [ ] 클리어 · 실패 보상 v1 (골드 · 휘장, 첫 클리어 보너스)

### Phase 2. 특성 · 캐릭터 · 흑마법사
- [ ] 직업 특성 트리 (냉기 마법사)
- [ ] 달라란 도서관 로그라이크 특성 페이지
- [ ] 캐릭터 생성 · 선택 (골드는 계정 공용, 장비는 캐릭터별)
- [ ] 흑마법사(고통): 부패 · 고통 · 어둠의 화살 · 부패의 씨앗 / 불안정한 고통 · 생명력 흡수 · 공포 · 어둠의 격노 · 악마의 마법진 · 불굴의 의지 · 생명석 / 임프 · 공허방랑자 · 지옥사냥개, 자원은 영혼의 조각
- [ ] 흑마법사 직업 특성 트리, 아이콘 약 30개

### Phase 3. 장비 · 가방 · 보상
- [ ] 와우식 능력치 (지능 · 체력 · 치명타 · 가속 · 특화 · 유연성), 특화는 직업별 효과
- [ ] 부위 16칸, 품질, 아이템 레벨별 능력치 예산, 무작위 2차 능력치
- [ ] 가방 (칸 제한, 비교 툴팁, 잠금, 판매, 분해)
- [ ] 스테이지별 전리품 표, 성과별 상자 등급

### Phase 4. 마법부여 · 보석 · 가챠
- [ ] 부위별 마법부여, 보석 홈 · 얼개 보석
- [ ] 가챠 3종 (확률 공개, 천장, 중복 → 재료)

### Phase 5. 퀘스트 · 금고
- [ ] 일일 · 주간 퀘스트
- [ ] 주간 금고 (활동별 칸 개방, 주간 초기화 때 선택, 금고 전용 희귀 아이템)

### Phase 6. 장기
- [ ] 직업 추가, 확장팩 챕터 추가
- [ ] 파티 던전 · 레이드 (서버 권위 실시간, 매칭, 역할)
